Demo of NewGardinerOmni

This page is a demo of an OpenType font constructed using hieropy. This NewGardinerOmni font can be found in the fonts directory of the repository of NewGardiner.

The font can dynamically interpret control characters. However, the shaping engines in most modern browsers are ill-equipped to deal with fonts of this complexity. Perhaps your browser is able to deal with individual top-level groups:

Rendering seems to fail for most browsers somewhere within the above steps. On my platform, Firefox starts to fail a little before Chrome and Edge do (although I have also witnessed the converse for some of the fonts discussed below).

Alternatively, the font can be compiled to handle subgroups to smaller depth and with fewer scaled copies per sign. This makes the font simpler, and more manageable for some browsers. The below line is rendered with a simplified font (maximum depth 3, with 4 scaled copies per sign, and with blue signs to distinguish it from the more complex font above). On my platform, this is rendered correctly with Chrome but not Firefox:

𓀹𓐱𓄤𓄂𓐰𓏏𓌞𓐱𓅱𓉐𓐰𓉻𓐰𓉐𓎟𓐰𓊪𓅱𓄊𓐱𓋴𓂋𓐰𓏏𓐰𓊃𓐰𓈖𓆓𓐻𓐷𓂧𓐰𓆑𓐸𓈖𓐰𓃹𓈖𓐰𓇼𓐰𓏏𓊹𓐱𓉞𓈖𓐰𓏏𓍋𓐱𓃀𓈋𓐰𓊖𓉞𓏏𓐰𓉐𓐰𓏥𓆑𓐰𓈖𓐰𓏏𓆥𓎛𓇬𓐰𓈖𓇓𓏏𓐰𓈖𓀴

Yet another alternative is to compile the font with a more primitive internal representation of dimensions. This will result in a coarser positioning, with more signs accidentally touching one another. Another problem is that cartouches longer than 3 EM can currently not be handled with this more primitive representation.
