Demo of NewGardinerOmni

This page is a demo of an OpenType font constructed using hieropy. This NewGardinerOmni font can be found in the fonts directory of the repository of NewGardiner.

The font can dynamically interpret control characters. However, the shaping engines in most modern browsers are ill-equipped to deal with fonts of this complexity. Perhaps your browser is able to deal with individual top-level groups:

𓀹𓐱𓄤 + 𓄂𓐰𓏏 + 𓌞𓐱𓅱 + 𓉐𓐰𓉻𓐰𓉐 + 𓎟𓐰𓊪 + 𓅱 + 𓄊𓐱𓋴 + 𓂋𓐰𓏏𓐰𓊃𓐰𓈖 + 𓆓𓐻𓐷𓂧𓐰𓆑𓐸 + 𓈖𓐰𓃹 + 𓈖𓐰𓇼𓐰𓏏 + 𓊹𓐱𓉞 + 𓈖𓐰𓏏 + 𓍋𓐱𓃀 + 𓈋𓐰𓊖 + 𓉞 + 𓏏𓐰𓉐𓐰𓏥 + 𓆑𓐰𓈖𓐰𓏏 + 𓆥 + 𓎛 + 𓇬𓐰𓈖 + 𓇓 + 𓏏𓐰𓈖 + 𓀴

Rendering seems to fail for most browsers somewhere within the above steps. On my platform, Firefox starts to fail a little before Chrome and Edge do.

Alternatively, the font can be compiled to handle subgroups to smaller depth and with fewer scaled copies per sign. This makes the font simpler, and more manageable for some browsers. The below line is formatted with a simplified font (maximum depth 3, with 4 scaled copies per sign, and with blue signs to distinguish it from the more complex font):

𓀹𓐱𓄤𓄂𓐰𓏏𓌞𓐱𓅱𓉐𓐰𓉻𓐰𓉐𓎟𓐰𓊪𓅱𓄊𓐱𓋴𓂋𓐰𓏏𓐰𓊃𓐰𓈖𓆓𓐻𓐷𓂧𓐰𓆑𓐸𓈖𓐰𓃹𓈖𓐰𓇼𓐰𓏏𓊹𓐱𓉞𓈖𓐰𓏏𓍋𓐱𓃀𓈋𓐰𓊖𓉞𓏏𓐰𓉐𓐰𓏥𓆑𓐰𓈖𓐰𓏏𓆥𓎛𓇬𓐰𓈖𓇓𓏏𓐰𓈖𓀴

In the encoding below of BM EA101, long lines were manually broken up, to make it easier for browsers to handle encodings with the more complex font (maximum depth 4, with 5 scaled copies per sign). On my platform, rendering is successfully achieved in Chrome and Edge, but only partially in Firefox.

Right-to-left text, horizontal or vertically, is inherently more difficult to implement in OpenType than left-to-right text. This is for future work.
